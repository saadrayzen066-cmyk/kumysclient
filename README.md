# Kumys Client

**Minecraft Fabric 1.21.4 · by aivex666 · kumys.xyz**

Здесь публикуются **готовые сборки**, не исходники Kumys Client.

## Скачать и запустить

1. Открой [последний релиз](https://github.com/saadrayzen066-cmyk/kumysclient/releases/latest).
2. Скачай **Kumys-Loader-Windows.zip** и распакуй весь архив.
3. Запусти **Kumys Loader/Kumys Loader.exe**. Не отделяй `.exe` от `app` и `runtime`.
4. Укажи локальный ник и нажми **«Запустить клиент»**. Игра, Fabric и Java
   скачиваются автоматически с официальных серверов; Gradle не нужен.

Для собственного Fabric-лаунчера есть **Kumys-Client-1.21.4.zip**;
для уже установленной Java 21 — **Kumys-Loader-Java21.zip**.
Не устанавливай две версии клиента одновременно.

## Обновления

В лоадере **1.2.0+**: **«Главная» → «Обновить»**. Новая сборка проверяется
по Ed25519-подписи и SHA-256; исходники, GitHub-токен и закрытый ключ в неё не включены.
Перезапускается только лоадер, не Minecraft. Моды обновятся при следующем
запуске игры; миры, настройки, ник и данные аккаунтов сохраняются.

Лоадер до 1.2.0 нужно **один раз заменить вручную**. Изменения становятся
доступны через кнопку только после публикации нового релиза.

## В клиенте

- GUI — **Right Shift** в мире; общий цвет — **Customize**.
- Музыкальная панель — **Render → Interface → Музыка**; перетаскивание в чате.
- **KineticLyrics** — слова трека в 3D; для проверки источник **«Пример»**.
- **Aura → spookytime(test)** — экспериментальный режим, не гарантия обхода сервера.
- Собственный Discord RPC подготовлен; до настройки Application ID не подключается.

Подробные инструкции находятся в `README.md` и папке `docs` внутри архивов.
Telegram: **https://t.me/kumysclient**.

## Ограничения и лицензии

Прямой запуск использует локальный ник, не авторизацию Microsoft. Для серверов
с проверкой аккаунта используй официальный Minecraft Launcher и свою лицензию.
Программа не запрашивает пароль аккаунта и не отключает защиту Windows.
`.exe` не подписан сертификатом Windows; SmartScreen может показать предупреждение.

Публичную готовую сборку можно скопировать или декомпилировать: отсутствие исходников
в репозитории не является абсолютной защитой от копирования. Подпись нужна для
проверки официальных обновлений, а не для запрета скачивания.

Права и уведомления оригинального Delta Client и сторонних компонентов сохраняются.
Лицензии — в `docs/THIRD_PARTY_NOTICES.md` внутри архивов. **Third-Party-Sources.zip**
содержит только штатные открытые исходники сторонних оптимизаторов и их лицензии;
он не содержит исходники Kumys/Delta, настройки пользователей или ключ издателя.
