## Запасные комплекты

В [релизе](https://github.com/saadrayzen066-cmyk/kumysclient/releases/tag/v1.4.0)
есть Windows ZIP с Java, Java21 ZIP/JAR и бесплатный Fabric ZIP для стороннего
лаунчера. Они не нужны для обычной установки через Kumys.exe. Если запускаешь
старый `Kumys Loader.exe` из ZIP вручную, распакуй весь архив с `app`/`runtime`.

Обновления проверяются встроенным ключом **Ed25519** и **SHA-256**; исходники
Kumys, закрытый ключ и пользовательские данные здесь не публикуются.
`Third-Party-Sources.zip` содержит upstream-исходники сторонних оптимизаторов
с их лицензиями; права третьих лиц сохраняются. Репозиторий — канал готовых сборок.

SmartScreen может предупредить о `.exe` без Authenticode. Подпись обновлений
не заменяет Windows-сертификат; отключать защиту не требуется.
Прежние релизы **1.2.0/1.3.0** сохранены без замены файлов.

Прямой запуск использует локальный ник. Для серверов с проверкой Microsoft
остается официальный Minecraft Launcher и собственная лицензия. Программа
не запрашивает пароль Microsoft и не обходит серверную авторизацию.
Публичные бинарные файлы можно копировать/декомпилировать; отсутствие исходников
в этом репозитории не является абсолютной DRM. Права авторов исходного Delta Client
и сторонних компонентов сохранены; уведомления — в `docs/THIRD_PARTY_NOTICES.md` архивов.
Музыкальный HUD, KineticLyrics и прежние игровые функции остаются;
Discord RPC требует собственного Application ID. **Telegram: https://t.me/kumysclient**.
